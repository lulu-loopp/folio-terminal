Folio · identity · round two

Four wordmarks, one gesture each

Round one was generic because it drew from “document”. This round draws only from the word. Folio has two literal meanings in the printing trade: a sheet folded once, giving two leaves — a pair of facing pages; and the page number printed on a page. Nothing below is a page-curl, a stack, or a file. Each option makes exactly one move and every other stroke is silent.

Where this lives. .apptitle in the mock-up: 12.5 px, colour --ink3, inside a 40 px .titlebar. Its left edge falls at x = 50 px — 12 (.drag padding-left) + 30 (.panel-toggle width) + 8 (gap). It appears in the vertical-tab layout only; horizontal tabs hide it.

Colour. Only real tokens from theme.rs. Actual-size renderings use title_text_muted (#A1A09C / #787878) because that is literally what --ink3 resolves to; the 3× proofs use title_text (#7A7974 / #9D9D9D) so the forms can be read. No option uses the accent anywhere. Each time an accent was tried it was the first thing that looked borrowed, so it came off — the cobalt rule above is this sheet’s own chrome, not part of any mark.

One skeleton. A, B and D are drawn on the same hand-built geometric sans — cap 100, x-height 74, stem 11, o a true circle — so that each option’s signature is the only variable between them. C is a different alphabet entirely.

A

Two leaves

The signature: the word’s own two os are exact mirrors of one another about the vertical axis that falls in the gap between the l and the i — and each ring is drawn thick on its outer side and thin on the side facing that axis, the way an open book is a solid block of paper at the fore-edge and vanishes into the fold. It belongs to Folio because the word already contains the spread: the two bowls sit at 108.5 and 263.5, whose midpoint is 186 — precisely the middle of the l/i gap. Nothing was added to find it; the fold was already in the name.

Portability — 1 sprite. One closed-path set, one currentColor, one [u8;3]: exactly the shape marks.rs already rasterises. Costs one new ChromeMark variant and one row each in SYMBOL_VIEW_BOX / SYMBOL_BODY (both arrays grow 27 → 28). No system font. Caveat: at 1× DPI the thin side of each ring is 0.73 device px, so resvg renders it as a grey hairline rather than solid ink — that is the intended up-close reward, but it means the leaf reading is a texture at actual size, not a statement.

B

One fold

The signature: there is no line — the fold is only a change of ink, a single vertical edge at x = 108.5 cutting straight through the bowl of the first o, with everything beyond it dropped one step to title_text_muted. It belongs to Folio because a folio is defined by one fold and by nothing else, and because a real fold has never been a drawn line: it is only ever the place where the light changes. A hairline was drawn here first and deleted — at 12.5 px a hairline is a full stem.

Portability — 2 sprites. svg_document substitutes one RGB per sprite, so two inks means two marks: the same word laid twice, clipped left-of-fold and right-of-fold, drawn as abutting rects. Both follow the theme (recto = title_text, verso = title_text_muted); nothing is hard-coded. Arrays grow 27 → 29. No system font. The one real cost: the fold seam must be snapped to a whole device pixel at layout time, or a sub-pixel gap or overlap will show at the join — the layout code must round the split x, not just the sprite rects.

C

The imprint

The signature: the word is set as book type — oblique stress, bracketed serifs, no geometry at all — and its only ornament is a folio: a centred point and an old-style 1 at 62%, standing off in the margin where a page number stands. It belongs to Folio because in typography the folio literally is the page number, so the mark states its own name twice, once in letters and once in the thing the letters mean. The period that first sat after the word was deleted; it was decoration, the numeral is the pun.

Portability — 1 sprite, zero accent. Drawn after Palatino (Hermann Zapf, 1949) — specifically its humanist proportions, its moderate contrast (stem 12 against a 7.5 hairline, about 1.9:1) and the −25° stress of its o, which is what makes the bowls read as written rather than constructed; the serifs are Palatino’s flared brackets rather than Caslon’s finer, flatter ones, because a flare survives a 9-pixel cap height and a hairline serif does not. It is a drawing after Palatino, not a revival, and no Palatino outline is used. One currentColor, one [u8;3], arrays grow 27 → 28. No system font. Caveat: this is the option most punished by low DPI — at 1× the hairlines land near 0.7 px and the folio numeral is about 4 px tall, so it is a whisper by construction; it wants a hinted minimum size or a 125%+ display to be fully itself.

D

The through-line

The signature: one number is different from the neutral skeleton — the F’s crossbar is dropped from the customary y 51 to y 63, the exact vertical centre of both o counters, so an invisible rule runs from the crossbar straight through the middle of both bowls and out the far side of the word. It belongs to Folio because that line is the line of reading — the one a terminal that reads should be built on — and because it is achieved by moving a stroke that already existed rather than adding one. There is no graphic element here at all; take anything away and it is a plain sans.

One currentColor, one [u8;3], arrays grow 27 → 28. No system font, no clip paths, no second ink.
