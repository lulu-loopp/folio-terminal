页内太挤 — 四种腾空间的办法

第一版把徽记打进页轮廓里。页的内沿是 x ∈ [4.08, 11.73]、折角以下 y ∈ [6.18, 14.03], 净地只有 7.65 × 7.85 个设计单位 = 15px 下 7.2 × 7.4 物理像素,六类徽记全挤在那块地里。 观感判定成立:拥挤不是徽记画坏了,是地不够。 这一轮不改徽记的语义(山丘日点 / 下箭头 / 尖括号 / 滑杆 / 网格 / 素纸),只换空间策略—— 四案各自用一种不同的办法把地腾出来。

不可违的约束(已裁):单色,图标穿所在表面的墨(树里 --ink3),零类型色;文件夹独享 --accent 蓝。手绘矢量,可移植为描边/填充路径,无外部图标库。七类:文件夹 / 图片 / markdown / 代码 / 配置数据 / 表格 / 纯文档——纯文档不盖章,徽章是主张,对陌生人诚实的主张是没有。

怎么读这份小样:每案三段。①真实语境——24px 行高、15px 图标、真实文件名、亮暗双主题,跟树里长得一模一样;②3× 矢量放大——看形;③1× 像素真相——把同一个 SVG 在浏览器里真的栅格化成 15×15 物理像素,再用最近邻放大 7 倍。第三段是镜子:糊掉的格子在那里一眼可见,骗不了人。
