## 2. 禁区与坑(全是踩过的)

**硬禁区**
- **不许碰 `dist\`** 里用户正在用的东西;**绝不许 kill 任何你没起的 folio 进程**。出新版就覆盖
  `dist\folio-next.exe` 或 `folio-next2.exe` 中**没被占用**的那个(被占的会 Access denied,
  而 `| tail` 会把这个错误吞掉、退出码还是 0 —— 用**时间戳**确认拷贝真的成功)。
- **不许改 `~/.cargo/config.toml`**:`jobs = 19`(24 核留 20%)是用户裁决,别删。
- **不许对 `.rs` 用 `sed`**(CRLF 会被毁)。要脚本就用 python(`io.open(..., newline='')`)或 Edit 工具。新文件一律 LF。

**反复咬人的**
- **`PSModulePath` 那条 export 已退役(2026-08-21,`test-env-immunity` 结案)**:当初「带 export 跑全量会挂、不带单跑就绿」是**两件方向相反的事**——
  (A)挂的两条测试(`real_powershell_input_reaches_a_viewport_owned_frame`、`sidecar_resize_keeps_history_navigation_on_a_clean_prompt_line`)
  是**墙钟总额被负载吹爆**,与 env 无关(改前/改后二进制同环境交替 7/8 vs 0/8);(B)export 真正救的是 **bt-pty 的 build.rs**——
  5.1 继承 pwsh 7 的 `PSModulePath` 会 `Get-FileHash` 找不到,现在 build.rs 自己算 5.1 的模块路径。两支探针改成**静默预算**(30s 静默 / 180s 天花板),
  `full_ring_blocks_writer` 的 20ms 假设也换成生产者自己的报告。规则进了 `CONVENTIONS.md`(超时按静默不按总额;A/B 必须交替)。
  **仍会抖的**:`dir_watch`(真竞态,已开单,§4)、`a_pathological_dollar_screen_arms_nothing…` 与 `finalized_line_ingest_stays_linear…`(时间比值门,多 cargo 并发必挂,单跑绿放行)。
- **i18n**:`crates/bt-app/src/i18n.rs` 的 `Text::ALL` 现在是 **419**,数字**手工维护**。
  新串一律**追加在 enum 末尾与 ALL 末尾同一块**。合并冲突的固定解法 = keep-both + 只留一个
  `ALL: [Self; N]` 头 + 重新数 + 加重复变体断言。**keep-both 会把函数或字符串字面量截断在半路**
  (今天发生过两次),解完必须 `cargo check`。
- **schema 版本撞车**:两条线同时占同一个版本号时,**后合的那条让号**(改迁移函数名、文档行、
  `Value::from(N)`、迁移表、常量、fixture 文件名与内部 `schema_version`、测试名与断言句子)。v16 是先例。
- **ui-probe**(`scripts/dev/ui-probe.ps1`):
  - 截图**校验中心像素归属**,别的 agent 的 folio 窗口盖上来会被拒绝(这是它该有的表现)。
  - **前台会被用户自己的窗口抢**,拒绝盲发按键也是对的;不要跟用户抢前台。
  - **中文 IME 会吃键**(`[Console]::Write` 被打成 `[Console: : Write`),要么切 en-US,
    要么走 `BT_PROBE_INPUT` 喂 fixture,要么只用 Ctrl 和弦。
  - `BT_PTY_DUMP` 命名的是**一个文件**,不是文件夹(给文件夹会报 Access denied,伪装成 ConPTY 失败)。
  - 隔离 `APPDATA` 的目录名**要 agent 独有**——用通用名会互相恢复对方的会话(今天发生过)。
- **A/B 必须同秒交替**:先跑一组再跑另一组会被机器负载差异混淆(用错了一次,结论翻案)。
- **DESIGN §1.2 的 workspace 划分是规划态,不是现状**:那里写着 `bt-richrender` / `bt-session` /
  `bt-shellint` / `bt-config`,这四个 crate **在 `Cargo.toml` 里根本不存在**,职责被并进了
  `bt-detect` / `bt-app` / `bt-persist`。凭那一段去找代码会扑空;以 `Cargo.toml` 的 members 为准。
  (今天开 F3 单时,「`bt-shellint` 这个 build 里不存在」就是这件事的一个实例。)
- **`vendor/alacritty_terminal` 必须留在 workspace.members 且版本精确锁**:否则 crates.io 上的
  0.26.x 会 out-resolve 掉本地 patch,**静默**把捕获钩子从构建里拿掉(`vendor/.../CONVENTIONS.md`)。
- **诊断开关(环境变量)**:代码里没有集中登记处,**这一条就是登记处**——新加一个就加在这里。
  下面全是 `folio.exe` 自己会读的。
  - `BT_MOUSE_TRACE=<文件>` —— **鼠标点击全程取证**(`crates/bt-app/src/mouse_trace.rs`)。
    与 `BT_PTY_DUMP` 同款:**命名一个文件**,不是文件夹;追加写、每行 flush;未设置(或设成空串)
    时闭包不被调用,零格式化开销。一行一站,带单调毫秒 + `window=<id>`:
    `mouse_input`(state/button/物理指针/`metrics_scale`/`swapchain_size`/`inner_size`/当前 route)、
    `chrome_mouse_input taken=1 at=<臂名>`(每个吃掉事件的出口 + `chrome_target_at` 的 Debug)、
    `pane_press`(命中的 cell、`pressed_cell_target`、该 cell 的 `HyperlinkHit` 与图片引用、
    以及 `forwarded=1` —— 开着 1000/1006 的程序把按下抢走时就是这一行)、
    `begin_local_selection`(press armed 的 route 与它许诺的东西)、
    `finish_local_selection`(origin/release 两个 cell、`single_click`、press 与 release 两次
    `HyperlinkHit` 的完整 Debug、`same_link`)、`activate_hyperlink`(uri、走了哪个臂、
    `file:` 解析出的路径与它是否存在/是不是目录)、`preview_landing_surface`(两个 `None` 出口
    分别带标签)、`open_preview_file` / `open_preview_image` 的进入与 `leave=no-landing-surface`,
    外加 `dpi stage=…`(与 stderr 上那行 `BT_DPI` 同样四个数,写进同一个文件好对时)。
    **它一条行为都不改**;`mouse_trace_station_tests` 三条钉子盯着「新加的 return 旁边不许没有一行」。
  - `BT_PTY_DUMP=<文件>` —— ConPTY 原始字节 + `.chunks` 到达边界(见上一条 ui-probe 的坑)。
  - `BT_PROBE_INPUT=<文件>` —— 不起 ConPTY,把文件字节直接灌进 Term。
  - `BT_STARTUP_TRACE=1`、`BT_RESIZE_TRACE=1`、`BT_LAYOUT_EVENTS=1`、`BT_IME_TRACE`、
    `BT_GIT_TRACE`(**空串 = 关**)、`BT_PERF_TRACE`(**空串 = 关**)、
    `BT_CHROME_DUMP=<文件>`、`BT_FOCUS_THUMB_DUMP=<文件>`、
    `BT_PSREADLINE_PROBE=<version>[,<policy>]`、`BT_BG`。
  - `BT_DPI` 不是开关:create/show/first-present/resized/scale-factor-changed 五个对账点**无条件**
    向 stderr 各打一行(`docs/M0-beta.md` §3)。
  - 仓库里另有一大批 `BT_*`,但它们是 `bt-replay` / `bt-repaint-oracle` / `bt-zoom-perf` 这些
    探针二进制和测试 fixture 的,**不是 `folio.exe` 会读的**。判据:
    `grep -rn 'env::var_os("BT_' crates/bt-app crates/bt-pty crates/bt-render`。
- **语义合并破坏**:文本上干净合并 ≠ 语义正确。今天多次:字符串表计数、快捷键表行数、
  cross-tab 的键类型变了、`WindowRuntime` 新字段没在新窗路径上被设。合完先 `cargo check`,再看新加的字段/行有没有被两边都照顾到。

## 5.5 不许违反的不变量(动代码前先确认你没在推翻其中一条)

这些是产品的地基,写在 `docs/DESIGN.md` 里。它们不是风格偏好,是**推翻了就要重做一大片**的东西。

**§1.1 核心不变量(五条)**
1. **Canonical Transcript 是真相**(对已冻结内容);活动网格的真相是 grid 本身;富内容是转录区间上的**可撤销装饰**。
2. **双平面 + 单向冻结 + 可变尾部单一所有者**:稳态 alacritty scrollback = **0**;任一时刻只有一个 mutable owner;
   Live→Frozen 严格单向,**无 thaw**。其中拆出的两句要分清:
   **终端坐标不变量(不可动摇)**——ConPTY/vendor 永远持有固定 N×M 网格,**富内容绝不触发 PTY resize**;
   **投影布局不变量(可放宽)**——视口怎么把逻辑行映射到像素是我们的事。
3. **文档与投影分离**:`HistoryDocument` 无布局;每视口一份 `ViewportProjection`。
4. **核心逻辑与 GUI 解耦**:纯 crate + 语料回放。
5. **Damage 驱动调度,完整帧合成**。

**§7.0 内容×形态三法则**
6. **状态属于内容,随行不分叉**——容器不持有状态。
7. **拖拽换容器,落点定容器**——载荷 = 内容身份。
8. **一切限制是政策不是结构**——不开放的组合必须是**显式政策记录**(可翻案),不许变成结构性阻塞。
   今天「无终端 tab」那一片就是这条被违反了一年后的修复:拆墙,而不是翻案。

**§7.1 贯穿性纪律**
9. 预览与提交**共用同一个布局求解器**。
10. 手势期间**命中目标保持身份**、未变化的状态不得丢失。
11. 弹出浮层由**集中控制器互斥**。
12. 实现为独立纯布局求解器,**不模拟 CSS flex**。
13. **hover 原则**(被两次升格为产品核心差异点):查询 hover 化、**提交必点击**;高频任务 ≤2 次滑动 + 2 次点击。

**§9 三道退出门**(验收硬指标,不是软目标):G1 resize 生命周期回放矩阵、G2 多投影一致性、
G3 锚点与版本协议。原文:**「三门任一不过 → 按 R10 降级砍功能,不顺延。」**
