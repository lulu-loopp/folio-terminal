## 五条关键发现（含两次被实测推翻的 Claude 预判）

**¹ 搜狗不把组字报给应用（最重的发现）。** 日志铁证：整场 63+ 个按键 0 文字、`ime_preedit` 只有 1 个且为空、只有最终 `ime_commit` 送达。搜狗把拼音串+候选全画在自己的浮窗里，对应用只报空 preedit。**这精确命中 Gecko `IMMHandler.cpp:1630-1632` 记录的 "Sogou 返回空组字串"。** 后果：**终端无法在自己的网格里渲染搜狗的预编辑，只能拿到最终结果**——但结果正确，无丢字。搜狗无"应用级内嵌组字"开关（`分窗口显示拼音和候选` 只控制拆不拆窗，不控制上报）。**严格审计门在搜狗这里如实报红（"no non-empty Ime::Preedit event"）——那道防伪造日志的门顺手成了输入法行为异常探测器。**

**² 中文拼音无 target clause，但要分两级说。** 三家的 `cursor range` 全程是塌缩 caret（a==b），0 个真区间——即便微信（**光标能按词跳**，比微软拼音的逐字母聪明）也是如此，且按词跳时**候选列表不变**，证明那只是光标导航、不是转换目标选择。**结论：这类输入法整串一起转换，不分段确认；M0 的预编辑渲染无需处理"高亮当前转换段"。** 措辞按主要来源收紧：Chromium `imm32_manager.cc:292-295` 对**所有** IME 都塌缩成 caret，这是生态通例不是中文特例。

**³ 搜狗第 2/3/4 项 N/A —— 应用层无从观测。** 这三项都依赖"应用能看见预编辑"，而搜狗不上报，所以在应用层没有可判的证据。搜狗内部处理正确（真人肉眼确认），但那不经过 winit 能观测的路径。**"无从观测"本身就是结论，不是没测。**

**⁴ 候选框连续跟随是 per-IME 的 —— Claude 的两次预判都被实测推翻。**
- Claude 原判"winit 缺 system caret → 所有中文输入法连续跟随都 FAIL"。**实测：只有微软拼音（而且它是 TSF 优先那家）第 7 项 FAIL；微信、搜狗都 PASS。**
- Claude 曾把搜狗设置图里"候选窗跟随光标"开着当成"跟不上的铁证"。**实测：搜狗默认设置下跟得好好的**（该设置关掉才会钉死）。
- **修正后的 M0 结论**：候选跟随是 per-IME 又 per-setting；system caret 补丁（照 Chromium 对 `LANG_CHINESE` 的做法）**只专治微软拼音的连续跟随**，不是普适兜底。做它无害（不破坏另两家），**建议 M0 实现以覆盖微软拼音**。
- **附带**：微信、搜狗第 7 项都出现"我们的蓝框卡顿、候选框流畅"——那是**我们的蓝框重绘在高频发坐标时掉帧**。M0 应**节流 `set_ime_cursor_area`**。

**⁵ 双拼 N/A（三家一致）。** 真人使用全拼，三家均未配置双拼。双拼与全拼走同一条 IMM32/TSF 通路，前序项已验穿，无新覆盖损失。

## 实测确认的、写给 M0 键盘/IME 层的硬规则

1. **组字期间应用照收每个按键**（winit #4508，对着本机 build 报的）：logical 全被抹成 `Named(Process)`，physical 透传。实测微软拼音组字期 128 个按键、27 个 `physical=Backspace`，**0 个泄漏成真退格**。**M0 必须按 `logical == Process` 丢弃，绝不能碰 `physical`**——否则 shell 吃掉真退格。
2. **失焦/切输入法时，待定组字被当场提交**（IMM32 标准行为，三家一致）：一次幽灵 commit 落在 shell 提示符上。M0 需决定失焦时半个组字如何处理。
3. **英文模式字符直接、正常到达**（三家一致，`logical=Character`）——搜狗的"隐身"只发生在中文组字，英文不受影响。

## 探针本身发现的两处缺陷（已在测试中修复/记录）

- **探针原本不记焦点**，而第 8 项判据里"丢焦点"三个字一直写着——测试中补了 `focus` 事件日志。
- **探针原本不记 `physical_key`**，导致 Backspace/Esc（组字期都叫 `Named(Process)`）在日志里无法区分，第 4 项证据一度只能靠行为签名反推——测试中补了 `physical_key`/`state`/`repeat`。
- **探针的 F4 标记键自己也被 IME 吃掉**（组字期 F4→`Named(Process)`→落空），由真人实测发现。**规矩：F4 须在 preedit 空时按。** 报告建议：探针在组字期禁用 F4 或提示"先提交再标记"。
