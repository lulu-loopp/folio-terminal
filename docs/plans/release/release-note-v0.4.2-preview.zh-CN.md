# Folio 0.4.2

**下载：**[zip](https://github.com/lulu-loopp/folio-terminal/releases/download/v0.4.2-preview/folio-0.4.2-windows-x64.zip)（Windows 10 1809 及以上 / Windows 11，64 位）· [dmg](https://github.com/lulu-loopp/folio-terminal/releases/download/v0.4.2-preview/Folio-0.4.2-macos-arm64.dmg)（macOS 14 及以上，Apple 芯片）

**下载：** 上方 zip 与 dmg 即为完整下载，其余为校验和、物料清单与源码。[English release note](https://github.com/lulu-loopp/folio-terminal/blob/main/docs/plans/release/release-note-v0.4.2-preview.md)

## 亮点

- 把文件拖放到分屏上，或粘贴刚刚截取的屏幕截图，路径便出现在命令行上，按该 shell 的写法加上引号；从文件列拖一个文件到终端中间也一样，边缘仍打开窗格。
- 排版后的公式保持排版状态：程序重绘屏幕时不再闪回 `$$…$$` 源码，调整窗口大小时更早的公式也不再退回纯文本。行内公式即使在提示符回来之后图片才就绪也能排版——新窗口的第一个 `cat` 也不例外——你的提示符永远不会被当作数学来排版，无论它写了什么。
- 程序打印的公式不会损害它所在的窗口：嵌套过深或表格过大的公式被拒绝并保持文本显示，公式无法运行程序，一个画不出来的公式不再连带整个窗口一起关闭。
- 键入和指针保持响应：未变化的画面不再重复绘制，没有移动任何内容的滚轮不再发布帧，调整窗口大小时不再在绘制之前把每个窗格的完整历史复制两遍。
- 重排或删除配置文件不再关闭窗口或启动错误的 shell，Folio 无法读取的 agent 配置文件按原样保留而非被覆写。
- 失去显卡设备——笔记本断电切换到电池、驱动程序自动更新——不再关闭 Folio 及其中所有 shell；窗口重新请求设备，在新设备上绘制。
- 在 Mac 上，标签页可拖拽重排或拖出为独立窗口，Shift+滚轮可阅读公式推到窗格上方的行；在两个平台上，退出时不再在停止应答的磁盘上无限等待。

## 变更

### 新增

- **将文件拖放到 Folio 上会把路径放到命令行上**——落在你放手的那个分屏上，按该 shell 的写法拼出，多个文件写在同一行。
- **剪贴板上的图片粘贴为 Folio 为之写入的文件路径**，截屏可直接交给命令使用。
- **从文件列拖一个文件到终端中间会粘贴其路径**；手下方的框在松手之前就告诉你会发生什么，边缘仍以窗格的形式打开文件。

### 改动

- **Folio 自身的日志现在标明窗口停止应答时正在回应的事件类型**，关于冻结的报告可以指出时间花在了哪里。

### 修复

- **在全屏程序中滚动时公式不再闪回源码**，把窗口拖回原来的大小也不再让公式退回未排版状态。
- **命令输出中的行内公式即使在提示符回来之后图片才就绪也能排版**，折行后调整窗口宽度时仍保持排版状态。
- **你的提示符永远不会被当作数学来排版**，无论它写了什么、无论它被重绘在屏幕的哪里。
- **全屏程序退出后打印的公式重新排版。**
- **一个公式不再被邻居的结果拖累**，一屏幕的公式同时到来时不再把前几个留作源码。
- **拖动窗口边缘不再让公式吞掉它下面那一行。**
- **两行包含相同公式的输出不再显示彼此的图片。**
- **一个已部分滚入历史的公式块不再被**它后面那一行截断。
- **点击滚动条旁的命令标记每次都跳转到该命令**，即使屏幕上有公式。
- **右键点击公式复制的是那个公式**，而非你正在输入的窗格中的公式。
- **嵌套超出 Folio 绘制能力的公式，或过大而画不出的数学表格，被拒绝并保持文本显示**，而非终止程序。
- **公式无法运行程序**，一个画不出来的公式不再连带整个窗口一起关闭。
- **键盘跟随被拖放的路径**：接收路径的终端获得键盘焦点，从其他程序拖入的文件把 Folio 带到前台，落在对话框下方或不在终端上的 drop 不会写入任何地方。
- **正在输入法中组字的文本永远不会被提交到另一个窗格**。
- **失去显卡设备不再关闭 Folio。**半成品画面被丢弃，重新请求设备，窗口在新设备上绘制之前显示的所有内容。
- **拖放的文件落在你松手的那个终端上**，即使 Folio 正忙或你上一次悬停在别处：位置在文件释放的那一刻读取。
- **关闭窗格或标签页不再暂停窗口**，等待其中的程序被关闭。
- **在 Mac 上，Shift+滚轮滚动排版后的公式推到窗格上方的行**，且横向滚动与 Windows 上一贯的行为一致。
- **退出 Folio 时不再在停止应答的磁盘上无限等待。**
- **关闭一个 reader 卡住的窗格不再挂起窗口。**
- **Folio 无法读取的 agent 配置文件按原样保留**，不会被覆写。
- **未变化的画面不再重复绘制。**
- **重排或删除配置文件不再关闭窗口**，也不再让窗格运行你没有选择的配置文件。
- **在 Mac 上，从终端启动的第二个 Folio 实例交接给已有实例**，不再成为设置和会话的第二个写入者。
- **在 Mac 上，不属于 Folio 的快捷键交给等待它的人处理。**
- **在 Mac 上，持续播放的视频不再随打开时间堆积内存。**
- **过大而无法编辑的 Markdown 文件在每次写入时显示文件当前的第一屏。**
- **被程序自身折行拆为两行的公式现在正确排版。**
- **更早输出中的行内公式在调整窗口大小时保持排版状态。**
- **排版后的公式在程序重绘屏幕时不再闪回源码。**
- **最大化或调整窗口大小时不再卡顿**，即使窗格背后有长历史。
- **公式源码背后的着色块停在文本结束的地方。**
- **在 Mac 上，标签页可拖拽重排或拖出为独立窗口**；拖动标题栏空白部分移动窗口。
- **以尖括号开头且包含非 ASCII 文字的 Markdown 行不再导致预览崩溃。**
- **显示公式源码只作用于屏幕上的那一处公式**，不再影响之后相同文本的每一处。
- **在窗格末尾的滚轮不再请求一帧与当前画面相同的帧。**
- **带 trace 的运行在读取 trace 的一方掉队时不再暂停。**

<summary>安装说明（SmartScreen、Gatekeeper、校验和）</summary>

### Windows

| 文件 | 说明 |
| --- | --- |
| `folio-0.4.2-windows-x64.zip` | 九个归属文件，打包在一个文件夹中 — `sha256:<hash>` |
| `folio-windows-x64.zip` | 同一份压缩包，名称在各版本间固定不变 — 同一个 `sha256` |
| `SHA256SUMS.txt` | 压缩包两个名称和物料清单的哈希，格式为 `sha256sum -c` 可读 |
| `folio-0.4.2.cdx.json` | CycloneDX 物料清单 |

将 zip 解压到存放程序的位置，运行 `folio.exe`。没有安装程序；保持解压后的文件在同一个文件夹中，覆盖旧文件夹即可保留设置。需要 **Windows 10 1809 或更高版本，或 Windows 11，64 位**。网页预览需要 **WebView2 Runtime**，Windows 11 已自带，Windows 10 通常也有。

`folio.exe` 和 `folio.msix` 由 **Weiyi Shi** 签名，自 0.2.0 起一贯如此，但签名不等于声誉，SmartScreen 在首次运行时仍可能弹出 **"Windows 已保护你的电脑"**：点击**更多信息**可以看到发布者为 **Weiyi Shi**，点击**仍要运行**即可通过。

校验下载文件，将 zip 和 `SHA256SUMS.txt` 放在同一个文件夹中：

```powershell
Get-FileHash folio-0.4.2-windows-x64.zip -Algorithm SHA256
```

或者在有 `sha256sum` 的环境——Git Bash、WSL、Linux：

```sh
sha256sum -c SHA256SUMS.txt
```

### macOS

| 文件 | 说明 |
| --- | --- |
| `Folio-0.4.2-macos-arm64.dmg` | 应用程序，已签名并经过 Apple 公证 — `sha256:<hash>` |
| `Folio-macos-arm64.dmg` | 同一个磁盘映像，名称在各版本间固定不变 — 同一个 `sha256` |
| `SHA256SUMS-macos.txt` | 磁盘映像两个名称的哈希，格式为 `shasum -c` 可读 |

打开磁盘映像，将 **Folio** 拖入"应用程序"文件夹。需要 **Apple 芯片 Mac，运行 macOS 14 或更高版本**；此预览版没有 Intel 构建。也可以用 [Homebrew](https://brew.sh)：

```sh
brew install --cask lulu-loopp/folio/folio
```

磁盘映像及其中的应用程序使用 Developer ID 签名，并经过 Apple 公证。首次打开时会弹出一个面板显示开发者名称，面板中有**打开**按钮；如果打开时没有出现**打开**选项，右键点击应用程序并选择**打开**，只需确认一次。如果弹出的面板提示无法验证开发者，或提示应用程序已损坏无法打开，说明下载到的内容与发布的不一致——对照校验和文件检查，并从发布页重新下载。

校验下载文件，将磁盘映像和 `SHA256SUMS-macos.txt` 放在同一个文件夹中：

```sh
shasum -c SHA256SUMS-macos.txt
```

**Folio 没有遥测、没有数据分析、没有崩溃上报。**连接网络的操作只有两项：在网页预览中打开的页面，以及更新检查——可在 设置 ▸ 常规 ▸ **检查新版** 中关闭。
