# Folio 0.4.0-preview

**下载：**[zip](https://github.com/lulu-loopp/folio-terminal/releases/download/v0.4.0-preview/folio-0.4.0-windows-x64.zip)（Windows 10 1809 及以上 / Windows 11，64 位）· [dmg](https://github.com/lulu-loopp/folio-terminal/releases/download/v0.4.0-preview/Folio-0.4.0-macos-arm64.dmg)（macOS 14 及以上，Apple 芯片）

**下载：**上方 zip 与 dmg 即为完整下载，其余为校验和、物料清单与源码。[English release note](https://github.com/lulu-loopp/folio-terminal/blob/v0.4.0-preview/docs/plans/release/release-note-v0.4.0-preview.md)

0.4 是第一个同时面向两个系统的版本。Folio 在 macOS 上运行：同一个程序，为 Apple 芯片构建，要求 macOS 14 或更高版本，窗格、文件列、Git 页和预览都在——两个系统有差异的地方跟随所在的平台，快捷键用 Command 组合键，菜单栏是原生菜单栏，窗口带 macOS 绘制的三颗按钮，一个按键可以从任何应用呼出终端，在任一系统上写的设置文件另一台也能读。另一半是超大 Markdown 文档的预览。文件打开即完整呈现，可以直接编辑，上限是 8 MB 的编辑上限——`只读 · 64 KB` 的头部没有了，可编辑的文件不再显示为只读——打开和输入都不用等整篇文档加载：一个三兆字节的文件从约 3.4 秒降到十分之一秒显示第一块内容，段落内移动光标的耗时降到无法计量。

## 变更

### 新增

- **Folio 在 macOS 上运行。**为 Apple 芯片构建，要求 macOS 14 或更高版本：窗格、文件列、Git 页和预览窗格不变，多窗口退出后恢复到上次的位置，agent 完成时仍然收到通知——快捷键页使用 Command 组合键，窗口带 macOS 绘制的按钮，菜单栏是原生菜单栏，两台机器共读同一份设置文件。
- **在 Mac 上，一个按键可以从任何应用呼出终端。**`⌃\`` 从任何应用拉出快捷终端，再按一次收起；这是快捷键页上的普通一行，无需 macOS 授权，Windows 上的 `Win+\`` 不变。
- **在 Mac 上，Folio 的程序坞图标提供新窗口和新标签页。**长按图标或右键点击，两项排在 macOS 自带的行之上——从其他应用也能用，所有窗口关闭后也能用。

### 改动

- **在 Mac 上，外观页不再提供亚克力。**Folio 在 macOS 上不模糊窗口后方的内容，这一行直接移除而非置灰到"关"；Windows 不变，两台机器共享的设置文件保留该值。
- **Markdown 文件打开即完整呈现，可以直接编辑。**第一次打开就读入全文，上限为 8 MB 的编辑上限，文档可以直接滚动到底部、光标随时可以进入；`只读 · 64 KB` 标记消失了，超过上限的文件仍然展示头部并标出实际大小，文本、CSV 和 diff 保持有界首次读取。
- **打开超大 Markdown 文档几乎没有等待。**只测量视口附近的块，其余按行数估算高度，滚动到视口时逐一修正，锚点把视线所在的文字固定住，上方高度变化时画面不跳：一个三兆字节的文件从约 3.4 秒降到十分之一秒。
- **在超大 Markdown 文档中移动光标和输入不再等待整篇文档。**文档在每次击键时共享而非复制，撤销从编辑本身推导，行索引和宽度增量更新；同一个文件的击键延迟从 143 毫秒降到 66 毫秒，段落内移动光标降到无法计量。
- **Markdown 预览中的徽章横向排列，不再逐个堆叠。**与其他内容在同一行的网络图片变为带 alt 文字的小标签，像文字一样换行，README 顶部四个徽章不再各占一整行；独占一段的图片仍然以卡片形式展示，本地图片不变。
- **Git 页的变更文件用文字说明发生了什么。**git 能报告的每种状态都有对应短语——`Modified`、`Added, staged`、`Conflict (both modified)`——git 自身的两个字母显示在旁边，变更行和展开的提交下方的文件都是如此。
- **鼠标停在文件上时弹出的卡片带有淡入效果**，与其他小标签相同的九十毫秒，不移动也不缩放；悬停等待时间不变，减少动效时仍然立即出现。
- **标题栏上非按钮的区域都可以拖动窗口。**两个标签页之间的空隙、标签页上方的空条、设置按钮周围的间距现在都能拖动窗口，双击行为不变。
- **退出时保留窗口持有的所有标签页。**一个尚在关闭的页面不会在退出途中把已经移除的标签页再次写入会话。
- **预览底部的状态行仅在有内容时显示。**页面延伸到显示区域的底部；"已保存"、文件在资源管理器中显示、磁盘上的文件发生变更等提示悬浮出现，持续到不再需要时消失；不可编辑的文件在路径行末端显示一把锁，点击进入页面后说明原因；图片信息移到同一行。
- **预览无法显示的文件提供用默认应用打开的选项**，出现在未知文件类型一直以来的卡片上——像素过多的图片、过大的文件、太小的窗格、当前机器无法播放的录制文件，窗格和弹出窗口都是如此。

### 修复

- **在 Mac 上，`Edit ▸ Copy` 和 `Edit ▸ Paste` 作用于当前查看的窗格。**在终端上方它们之前完全无效；现在可以复制终端的选中内容或正在编辑的文件中的选中文字，粘贴到持有键盘的那个窗格。`⌘C` 和 `⌘V` 不变。
- **在 Mac 上，标签页占满标题栏全宽。**此前标题栏为四个窗口按钮留出了空间，而实际只有一个按钮，标签名被一条宽空白带遮住；934 点宽的窗口中七个标签页现在各有 91 点宽，名称完整显示。
- **在 Mac 上，从程序坞或访达启动的窗格可以读取本语言的输入。**以这种方式启动的 shell 没有从 macOS 获得语言设置，`天下为公` 显示为字节、ASCII 以外的文件名显示为问号；在没有匹配的 locale 时，Folio 告知已知信息——此窗口读取 UTF-8——不替用户选择地区，也不覆盖已有设置。
- **预览在光标移动和编辑后复用已测量的 Markdown 排版**，块的滚动偏移在文档重新解析时复位。
- **卡片上的表格重新对齐。**卡片的行按列布局，与窗格自身的网格一致，含中文的表格边框在每一行都对齐。
- **卡片在窗口调整大小后保持相同内容**，`Alt`+滚轮在反转方向到最旧内容时立即响应。
- **Git 页的 `REMOTES` 不再带有无人设置的高亮。**组标题在静止时暗色显示，鼠标移过时变亮，任何时候都没有色块；整行仍然可以点击。
- **设置中引用配置文件的选择器显示各配置文件的标记**，标记的样式和大小与新标签页 `⌄` 菜单一致，选择器关闭后仍然显示。"默认配置文件"不借用任何标记。
- **输入拼音时，光标位于已输入内容的末尾。**在已有的中文字符上方编写候选时，之前会残留半个字符，光标将其当作一个宽字符而站在中间。
- **按下打开菜单的按钮时菜单关闭**——预览的 `Open ⌄` 药丸、窄行中代替文件夹的 `…`、弹出窗口中提交图的分支列表。
- **排版耗时的公式在就绪时立即显示**，不再等待滚动、调整大小或打开其他文件。
- **键盘布局生成的字母到达 shell。**`ü`、`ä`、`ö`、`ß` 以及其他布局在 ASCII 以外合成的字母之前完全不发送；现在按原字节发送。
- **窗格右侧的命令标记与 shell 同步。**命令成功的勾号或失败的红色标记在 shell 报告的那一帧绘制，不再等待下一次按键或鼠标移动。
- **Windows 键的组合键不再把字母打进输入框。**`Win+C` 之前会在搜索面板、搜索框、名称编辑、分支输入、提交图的搜索和正在编辑的文档中输入一个 `c`。

完整列表见仓库中的 `CHANGELOG.md`。

## 下载与校验

### Windows

| 文件 | 说明 |
| --- | --- |
| `folio-0.4.0-windows-x64.zip` | 九个归属文件，打包在一个文件夹中 — `sha256:66da4ce336f90b032ce6900dda17197f0b865ca7080a65c35f3995cf0997f512` |
| `SHA256SUMS.txt` | 压缩包和物料清单的哈希，格式为 `sha256sum -c` 可读 |
| `folio-0.4.0.cdx.json` | CycloneDX 物料清单 |

将 zip 解压到存放程序的位置，运行 `folio.exe`。没有安装程序；保持解压后的文件在同一个文件夹中，覆盖旧文件夹即可保留设置。需要 **Windows 10 1809 或更高版本，或 Windows 11，64 位**。网页预览需要 **WebView2 Runtime**，Windows 11 已自带，Windows 10 通常也有。

`folio.exe` 和 `folio.msix` 由 **Weiyi Shi** 签名，自 0.2.0 起一贯如此，但签名不等于声誉，SmartScreen 在首次运行时仍可能弹出 **"Windows 已保护你的电脑"**：点击**更多信息**可以看到发布者为 **Weiyi Shi**，点击**仍要运行**即可通过。Folio 尚未上架 winget。

### macOS

| 文件 | 说明 |
| --- | --- |
| `Folio-0.4.0-macos-arm64.dmg` | 应用程序，已签名并经过 Apple 公证 — `sha256:346eb5a3fc2992513e141b0881762c2f85221b35d1be3a6223f1e7463e700dfd` |
| `SHA256SUMS-macos.txt` | 磁盘映像的哈希，格式为 `shasum -a 256 -c` 可读 |

打开磁盘映像，将 **Folio** 拖入"应用程序"文件夹。需要 **Apple 芯片 Mac，运行 macOS 14 或更高版本**；此预览版没有 Intel 构建。也可以用 [Homebrew](https://brew.sh)：

```sh
brew install --cask lulu-loopp/folio/folio
```

磁盘映像及其中的应用程序使用 Developer ID 签名，并经过 Apple 公证。首次打开时会弹出一个面板显示开发者名称，面板中有**打开**按钮；如果打开时没有出现**打开**选项，右键点击应用程序并选择**打开**，只需确认一次。如果弹出的面板提示无法验证开发者，或提示应用程序已损坏无法打开，说明下载到的内容与发布的不一致——对照校验和文件检查，并从发布页重新下载。网页预览使用系统自带的 WebKit，无需安装其他组件。

**Folio 没有遥测、没有数据分析、没有崩溃上报。**连接网络的操作只有两项：在网页预览中打开的页面，以及更新检查——可在 设置 > 常规 > **检查新版** 中关闭。

## 已知问题

- **表格的标题行刚好在视口上方时，绘制的表格会消失。**将标题行滚动回视口内即可恢复。
- **表格单元格中程序换行处丢失的空格不总能补回**——标点、数字或中日韩字符旁的换行在拼接时不带空格。
- **网页预览在响应页面消息框后显示的提示被页面遮住。**页面已被响应并继续运行。
- **窗格移动时，两个网页预览可能重叠约五分之一秒。**静止的窗格不会重叠。
- **保存在晚于主显示器枚举的显示器上的窗口**恢复到主显示器。显示器只枚举一次，在窗口创建之前完成。
- **曾有一次报告窗口在移到第二个显示器后上半部分绘制为黑色**，未能复现。如遇到此问题，请附上 `%APPDATA%\Folio\diagnostics.log`——Mac 上为 `~/Library/Application Support/Folio/diagnostics.log`。
- **Windows：Folio 无法作为 Visual Studio Code 的面板**；压缩包中的 `folio-here.cmd` 可以将其设为 VS Code 使用的外部终端。
- **Windows：`.webm` 需要从 Microsoft Store 安装 VP9 或 AV1 Video Extension。**原版 Windows 不自带，没有扩展则无法显示静帧和播放。
- **macOS：以崩溃结束的运行**会将报告留在系统统一存放的位置 `~/Library/Logs/DiagnosticReports`；下次启动 Folio 时，日志中会标注该文件名，不会复制到其他位置。
