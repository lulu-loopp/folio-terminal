# 内置游戏总盘子(用户定稿 2026-08-31)

**3 轻 + 2 中 + 1 重**,全部:单机离线、随时暂停、自动存档、agent「等你回答」到达即自动暂停并让位、无内购无遥测、借玩法不借皮(名字/美术自创)、reduced-motion 生效。工程形态见 pen-sort.md 第四节(游戏座位 + 纯逻辑 crate + `folio game <name>` 子命令)。

| 档 | 游戏 | 一局时长 | 角色 | 状态 |
|---|---|---|---|---|
| 轻 | **打字流星**(词落打消,命令行词库) | 30s–2min | **默认门用游戏**;终端身份最正 | 待规格 |
| 轻 | **跑酷**(光标跳字符障碍) | 30s–2min | 可选门 | 待规格 |
| 轻 | **2048** | 2–10min | 回合制,暂停最顺;可选门 | 机制 MIT 出身,零包袱 |
| 中 | **分拣益智**(排排排家族) | 3–15min/关 | 主打;+1 临时格走门用游戏 | 规格已定 pen-sort.md |
| 中 | (留空待定) | — | 候选:接龙、弹球加强、放置挂机(放置最配数小时等待) | 待裁 |
| 重 | **幸存者-like**(走位+自动攻击+三选一升级,ASCII) | 15–20min/局 | 长局;肉鸽重开撑数小时 | 待规格 |

**门机制**(pen-sort.md 已录):卡关要 +1 临时格 → 打一局门用游戏达标解锁,本关有效,每关至多 +1~2;目标分默认给、设置可自改(归零=交权给用户)。门用游戏默认打字流星,设置里可换成跑酷/2048。

**施工顺序**:打字流星(门+管线地基)→ 分拣益智 → 跑酷/2048 补齐轻档 → 幸存者-like → 中档二号。全部排在 v0.1.0-preview tag 之后。
