## 3. 三条结论

### 3.1 铃的闸门是「焦点」,不是「时长」——而那个焦点事实 Folio 从不供给

B 与 D **prompt 一模一样、回合一样短**,唯一的差别是 D 在 prompt 之前发了一次 `ESC [ O`。
**B 零铃,D 一铃。** 这是一个单变量对照。

而 Claude Code **自己开了 `?1004h`**——录音 B 的私有模式序列是:

```
      7  ?1004h     ← ConPTY 自己的(DESIGN §7.1.5i 已证:每个会话在任何程序跑起来之前就有这一条)
     15  ?9001h     ← ConPTY
     54  ?2004h     ← 应用的(括号粘贴)
     62  ?1004h     ← 应用的(焦点上报)
     86  ?1049h     ← 应用的(备用屏)
```

**它要焦点上报,而 `bt-app` 一个字节都不发**(DESIGN §7.1.5i 记的全仓 `\e[I`/`\e[O` 零命中)。
于是在 Folio 里,Claude Code 对「用户还在看吗」这个问题拿到的是一个**从不变化的前提**,
而它按那个前提决定了不打扰你。**「该亮不亮」在这里有了一个 Folio 侧的、可修的成因。**

C 在不发焦点事件的情况下也响了一枚,所以时长(或别的什么)是**第二条独立的触发条件**;
本文件不去猜它的阈值——单变量对照已经把「焦点」这一条钉死,而那一条正好是我们能修的那条。

### 3.2 Claude Code 不发 OSC 133、不发 OSC 9;4、不发 OSC 777

三段有效录音全部零命中。推论:

- **进度环通道对它永远是空的**(§7.1.5b 的「进度」一态在 agent 场景下无源)。
- 它**全程住在备用屏**(`?1049h` 在第 86 字节,`?1049l` 在第 191101 字节,中间一次没退)。
- 今天 tab 上关于一个 claude pane 的一切,来源只有三样:**它住在备用屏**、**它写了多少字节**、
  **那一声铃**。

它发的 OSC 只有两种:`OSC 0`(标题)与 `OSC 8`(超链接,每帧一对,指向本次会话的 `claude.ai/code/session_…`)。

### 3.3 标题是一个转轮,而转轮本身零语义

录音 C 的 49 次改题里,字形在 `✳` / `◐` / `◑` 之间循环,**`✳` 在忙碌中段出现了两次**
(偏移 849489 与 946320,两侧都是 `◐`/`◑`)——**没有哪个字形专属于空闲**。
空闲时发生的事情是**改题停了**,而改题停 = 帧停,帧停两义:可能是在等你,也可能是它在想事、
这一秒没画。DESIGN 早就写了「标题转轮停止**不推荐**当 awaiting」,这段录音是它的证据。

标题的另一半是真的:`OSC 0;<字形> <任务名>`——`◐ Sleep 40`、`◑ Reply with ok`。
**任务名是它主动报的**,归 P1-12(自主命名的优先级链:手动 > 程序标题 > cwd),不归本块。

## 3.4 勘误与补注(2026-08-25 晚,评审折入时加)

本文件的四段录音、逐字节判读与三条结论**一条都不改** —— 下面是它们**覆盖不到**的边界,写出来是为了不让人把它们读过头。

- **只量了一条通道。** 四段录音走的全是 `preferredNotifChannel: terminal_bell`。Claude Code 的 **hook 通道一个字节都没测** —— 它的门归片 A3,不归本文件。
- **`ESC [ I` 没测。** 单变量对照只发了 `ESC [ O`(离开),整场不发 `I`。所以「焦点是闸门」这一条,证的是**离开**这一半;**回来**那一半仍是待测(plan §10.5 的补测点 1,录音 E)。
- **`terminalSequence` 白名单拒收 OSC 1337。** 官方 hooks 文档(2026-08-25 逐字取回)明写白名单只有 OSC `0`/`1`/`2`/`9`/`99`/`777` 与 BEL,并逐字点名 OSC 1337 被拒。这不是本文件量出来的,但它与 §3.2 的「它发的 OSC 只有两种」互相印证:**Claude Code 发不出 `RequestAttention`,无论 hook 怎么写。** 详见 plan §10.4.2。
- **版本足够**:录音用的 `v2.1.241` ≥ plan §10.4.1 白名单里所有 notification type 的最低版本(`agent_needs_input` 需 ≥ v2.1.198,`quota_auto_resume_*` 需 ≥ v2.1.234)。

## 4. 顺带记下的两条

- ConPTY 的会话开头握手在这台机器上是 `\e[1t` `\e[c` `\e[?1004h` `\e[?9001h`,与 §7.1.5i 记的一致。
- Claude Code 退出时把自己开的模式关得很干净(`?1049l` `?1006l` `?1003l` `?1002l` `?1000l`),
  并把标题清成 `OSC 0;`——§7.1.5i 那条「死程序留下的鼠标上报」的病灶不在它身上,
  在**被强杀**的它身上(那一节的现场就是「Waiting for 7 background agents」时被结束)。
