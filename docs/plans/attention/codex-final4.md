# Codex 终审第四轮（极窄）：wait 正常出口合同

复核日期：2026-08-25。范围只含 `codex-final3.md` 唯一剩余项：『每一种 wait 都有可达正常出口』的全称合同与 `agent_needs_input` 未答自结束分支之间的矛盾；不重开其余产品裁决。

## 结论

**闭合。**

§11.4.2 的标题现已把主张收窄为“每一种进 wait 的事件都有一条已写明的出口”，并当场注明 agent 行存在一格不可达条件、转指 §13.1.4；它不再声称每一格都有可达的正常出口。表内 `agent_needs_input` 行也同时保留 `UserPromptSubmit`、`SessionEnd` 与 TTL 600s 的有界退出路径。

§13.1.4 首段已明确撤回 v5 的全称原句，现行合同改为：除 `agent_needs_input` 外，正常出口在等待真正结束时可达；agent 的“后台自行结束且用户从未 Answer”分支没有正常出口，由边界 / TTL 兜底。该段及 §13.1.3 还共同写明了不可达格的消失路径：逐字取证两端的 background session id，令 agent kind 进入 id 模式后，`agent_completed` 走第一支按 key 精确退出。

§13.1.4 标题、§11.4.2 的 v5 说明及收口句中仍出现的“每一种 wait 都有正常出口”，均处在被重述、被纠正或历史原文记号的语境中；现行规范句与逐行表格没有再把它作为无例外全称合同。因此它们不与 agent 行的 ack 闸结论冲突。

## 总判定

**完全闭合，无需继续修改。** `codex-final3.md` 的唯一剩余矛盾已消除；本轮范围内没有新的阻断项。
