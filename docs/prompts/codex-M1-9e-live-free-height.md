# M1.9e 任务书:live 自由高度——落地即渲染,且前后视觉一致(方案 1a)

档位 xhigh。基线 = M1.9c-r2 之后的工作树。**这是 M1.9 系最大的一片,
也是唯一能同时满足用户两项要求的路径**;按你自己在独立咨询里给出的
推荐方案实施(咨询报告结论已被用户采纳)。

## 用户裁决(已批,照此实施)

- 目标:**所有 `$$` 块落地即渲染**,且 **live 与冻结视觉完全一致**。
- 接受的代价:公式撑高使总高超出窗口时,**live 屏顶部内容被推出视口**
  (可滚动回看),**底部永远可见**。
- 不变量拆分已写进 DESIGN(§核心架构判断 2):
  - **① 终端坐标不变量(不可动摇)**:ConPTY/vendor 永远固定 N×M,
    应用按行列绝对重绘,富内容**绝不触发 PTY resize**、不改变逻辑
    行列语义;
  - **② 投影布局不变量(放宽)**:视口把逻辑行映射到像素是我们的事,
    live 行**可以**拥有自由像素高度。
- **排版模式由定界符决定,绝不由生命周期决定**:`$$` 在 live 与冻结
  两侧**都是 display**;math mode 进入 render/cache key。

## 实施要点(你的咨询报告推荐,逐条落实)

1. **ConPTY 固定**:公式高度绝不触发 PTY resize(护住不变量 ①)。
2. **live 高度树**:`ViewportProjection` 增加 live block 高度树 /
   visual-row map,使用**与冻结侧同款的 display raster、1000‰ scale**
   (不缩放、不 inline、不适配)。
3. **底部保底 + 顶部溢出**:Bottom 状态保证屏幕底部可见;溢出发生在
   顶部,可本地回看;新增**网格外 `N rows above` 指示**(与既有
   `N lines below` 同族的呈现)。
4. **锚语义**:primary 用连续文档锚;alt 用 screen-local overflow state,
   不进入 primary 全序。
5. **输入映射统一**:鼠标转发依据**最后已呈现帧**的显式
   visual-row→GridPoint 映射(m1.8b 的 live 相对坐标语义在新几何下
   重新表达);选区继续走 `CellAnchor`;**cursor、IME 光标区、选区 y、
   滚动锚全部走同一个 live prefix map**,不许各算各的。
6. **失效同帧撤销**:source/generation 变化时,artifact、额外高度、
   源文本抑制**同帧**一起撤销;resize epoch 与 alt 切换一律清空。
7. **artifact 交接**:raster/cache key 去除 live/frozen 身份差异;
   滚出定稿时校验 source/span 后**复用同一 artifact**,避免形态变化
   与重复上传。
8. **安全护栏**:初期「**整屏额外高度 ≤2 行**」;超限的处置必须诚实
   ——按你论证的最优策略(建议:超限时最老的块回退源码而非缩放,
   保持"要么一致要么不渲染",不许出现第三种形态),并写明依据。
9. **借空行快速路径**:M1.9c 的借用逻辑保留为"不增加总高度"的优先
   路径(块下方有真空白行时优先吃掉它,不制造顶部溢出),
   **并修好它当前在真窗口不生效的缺陷**。根因 M1.9c-r2 已定位并确认:
   `invalidate_live_row`(`session.rs:798`)对**任何 damage** 先加
   revision、再**无条件删除**覆盖该行的 decoration;TUI 把借用的空行
   "重绘成空行"时**内容一个字没变**,装饰却被杀,持续重绘又使该行
   永远稳定不下来。

10. **失效判据改为"内容变化"而非"damage 事件"(本片核心修正)**:
    第 9 条的根因暴露了一条更普遍的错误——**被重绘 ≠ 内容改变**。
    live 装饰的失效必须以**内容/revision 的实际变化**为准:同一行被
    重绘成完全相同的内容时,装饰应当**存活**。这条对方案 1a 尤其要命:
    备用屏应用每帧重绘整屏是常态,若沿用"damage 即杀",自由高度的
    公式会被持续屠杀、永远无法稳定。
    - 论证并实现内容级失效判据(可复用 m1.8d 的呈现等价思路:
      比较**内容**而非事件);
    - 明确哪些情形仍必须立即失效(内容真变、滚动、清屏、alt 切换、
      resize epoch、source/generation 变化);
    - 回归:同内容重绘 N 次 → 装饰存活、无重复光栅;内容真变 → 同帧
      撤销;spinner 每 100ms 重绘邻行 → 公式不受影响。
