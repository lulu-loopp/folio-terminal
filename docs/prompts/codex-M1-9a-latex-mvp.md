## 范围与裁决

1. **检测(转录层,冻结行专属)**:
   - 只对**已定稿(Frozen)**的转录逻辑行运行——live 区绝不检测(稳定态
     检测原则;live 行滚出定稿后自然进入检测队列)。
   - 块级 `$$...$$`:同一逻辑行内成对,或连续逻辑行构成的块(首行 `$$`
     开、尾行 `$$` 收)。保守优先:不成对、嵌在代码围栏内(检测不了围栏
     就先只排除"行内还有其它内容夹杂"的可疑形态)、超长(>8KB 源)一律
     不装饰。**误报零容忍集**进测试:shell 里的 `$$`(进程 id)、diff/日志
     里的字面 `$$...$$` 单行残片、`\$$` 转义。
   - 走 bt-detect 既有生命周期:检测在 worker 侧异步,带 generation,
     ED3/淘汰/重排失效丢弃零泄漏(G3 语义)。
2. **渲染管线(异步,绝不阻塞呈现)**:
   - TeX→排版:优先评估 katex 系 Rust 方案;不可行则报告候选
     (latex2mathml+mathml 渲染、typst 数学子集等)与取舍,停下等审。
   - 排版结果→SVG→resvg 栅格(按当前 DPI/字号缩放)→wgpu 纹理。块纹理
     独立管理(不进 glyphon 字形图集——尺寸量级不同),带字节预算与淘汰
     (借 m1.8e 的 O(1) LRU 模式),纹理随 DPI/字号变化失效重排。
   - 语法错误/渲染失败:**安静降级**——该块保持源码文本显示,记一个
     trace 事件,不弹任何错误 UI(§7.2 一个区域一种语言;失败的块就是
     普通文本)。
3. **呈现(视口合成)**:
   - 装饰完成的块在视口中**替换其源行的显示**:源行仍在转录(搜索照搜
     源码,§7.1.5d 已定;复制语义 M1.9b 处理),显示位置由块占据,块高度
     进入高度树(G2 多投影下不同宽度各自正确)。
   - 块几何遵循 §7.3/§7.4/§7.5:贴内容宽不贴窗口宽、上下等距不轴居中、
     超宽跟随 wrap 设置(on=块内横滚;off=随 pane 横滚)、超高受 blockMax
     设置钳制(块内滚,设置 UI 已在原型定稿,原生端做同语义)。
   - **7.5b(高度网格量化)本片裁决=不量化**(自由像素高度),SourceMap
     之前重议——在代码注释与结果报告里明示这个决定。
   - 锚定:块随逻辑行锚滚动;上滚/下滚/resize 反流后块跟行走(G3 锚迁移
     语义,新增回归)。
4. **门禁**:
   - 既有全绿不回退:G1 生命周期矩阵、G2 多投影、G3 锚点、vendor 182、
     m1.8d/r2/e/f 全部回归。
   - 新增:误报零容忍集;检测→装饰→呈现端到端(feed 含 $$ 的转录 →
     断言块出现在正确锚位、高度正确、多投影一致);失效链(ED3/清屏/
     resize 反流后块正确消失/迁移/重渲染);异步渲染不阻塞(渲染慢时
     视口先以源码显示,完成后原位替换——断言中间态合法)。
   - cargo test --workspace --locked、clippy --all-targets -D warnings、
     fmt --check;vendor 零改动。
5. **性能红线**:检测与渲染全程 worker 侧;主呈现路径每帧新增成本上限
   与 m1.8e 同量级(行缓存命中路径不得回退);BT_PERF_TRACE 增加块渲染
   耗时与纹理驻留字节。
