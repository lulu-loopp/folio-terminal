# M1.7 滚动回溯与选区复制

## 侦察结论与接线图

未发现需要停单的架构级阻塞。既有 `bt-transcript` 把尚可改写的滚出物理行保存在
staging candidate，把定稿逻辑行保存为 `FrozenLine`；vendor scrollback 仍为 0。渲染此前只从
`TerminalAdapter::visible_row` 拍 live 网格，本片把同一帧改接为：

```text
vendor Term (scrollback=0)
  └─ removal facts → bt-transcript staging → FrozenLine + HistoryDocument anchors
                          │                         │
                          └──────────┬──────────────┘
                                     v
bt-viewport: frozen + staging + live 连续行空间，按窗口只物化相交 FrozenLine
                                     v
bt-render: cell background → selection background → status → cursor → text
                                     v
bt-app: winit 键盘/滚轮/鼠标 → 本地视图，或按 TermMode 转发 PTY
```

`ViewportProjection` 的 frozen 高度/顺序索引支持 append-only 增量更新；上滚窗口只布局命中的
逻辑行，不扫描并物化整份转录。新输出增加连续空间底部时，当前 offset 同量增加，因此旧窗口
保持冻结，并在右下角显示 `N lines below`。回底、任何真正发送到 PTY 的键盘/粘贴/IME/鼠标
输入都会恢复跟随。

## 输入与选择政策

- Win32 `SPI_GETWHEELSCROLLLINES` 是每格滚轮行数裁判（也处理 page-scroll 设置）；winit
  `LineDelta` 只提供格数。触控板 `PixelDelta` 按实测 cell height 累积。
  Shift+PageUp/PageDown 滚整页，Ctrl+Home/End 到顶/底。
- alternate screen 不使用本地历史。鼠标应用模式优先转发；1006 开启时发 SGR，旧模式保留
  X10 fallback。无鼠标模式但开启 alternate-scroll 时，滚轮转为当前 DECCKM 对应的方向键。
  Shift 绕过应用鼠标转发；alt screen 上仍可本地框选，但滚轮不进入本地历史。
- 像素命中是 `bt-render::CellMetrics::hit_test` 的公共纯函数，统一处理 padding、物理像素、DPI
  和网格边界，下一片超链接可直接复用。
- vendor `selection.rs` 的 Point 只能表达 vendor grid，不能跨 transcript/staging/live，直接复用
  会重新引入第二份历史坐标。因此本片复用其 anchor/range、线性/词/行三种语义，但端点类型使用
  既有 `ContentAnchor`，由 `HistoryDocument` 负责跨平面迁移。
- 单击拖拽是线性选择，双击按词，三击按显示行。固定词分隔符为 whitespace 加
  `` `~!@#$%^&*()-=+[{]}\|;:'",.<>/? ``；以后由设置项接管。wide/emoji spacer 与 lead
  共享 anchor，live→staging 迁移还携带 cell-column→grapheme 映射，端点不能切开簇。
- 选区背景使用 Campbell 派生常量 `[0x26, 0x4f, 0x78]`，不改终端前景；光标画在选区之上。
- Ctrl+C 有选区时复制并清选区，无选区时仍发 `0x03`；Ctrl+Shift+C 无条件走复制命令。
  copy-on-select 未实现，留给设置片。
- 抽取以源语义为准，不以当前视口折行为准：soft wrap 拼接，hard row 之间写 CRLF；每个硬行
  末尾及最终末尾裁掉 space/tab。Win32 `CF_UNICODETEXT` 写入与 M1.6 读取共用 `bt-platform`
  审计边界。
- 新选区替换旧选区；发送输入清除选区。FrozenLine 不可变，可长期保留选择；staging/live
  缺少逐格 mutation event，因此任何 PTY 输出到达时保守清除涉及 mutable plane 的选择。
  这比“只在选中行实际变化时清除”更严格，但不会留下复制旧内容的悬空选择。
- 鼠标操作不修改 `Preedit`。上滚隐藏 live cursor/preedit overlay，回底后仍由后续 IME 事件
  接管；不取消、不提交也不吞掉组字。

## 验收边界

自动测试覆盖滚动 clamp/冻结锚定、宽簇词/行边界、soft/hard 抽取、SGR 与 legacy mouse、
alt-scroll 字节和 Ctrl+C 双语义。`scripts/dev/ui-probe.ps1` 注入的鼠标/键盘进不了 winit，故
滚轮手感、拖选手感、真实 vim 定位和 IME 交互必须按
`scripts/dev/m1-7-scroll-selection-acceptance.ps1` 人工验收。

协调者仍可用 `BT_PROBE_INPUT` 直灌足量带换行 VT 输出，检查 frozen/live 拼接、选区背景与
右下状态的像素结果；这种截图只能证明渲染结果，不能冒充真实滚轮或拖选事件覆盖。

为显影背景相关渲染缺陷，启动前可临时设置 `BT_BG=#RRGGBB`。该值只覆盖默认背景，保持为
sRGB 字节并继续走 renderer 既有的唯一 sRGB→linear 上传边界；Win32 class brush、swapchain
clear 与 SGR 49 因而使用同一颜色。非法值被忽略并输出一行 `BT_THEME` trace；未设置时仍为
Campbell `#0C0C0C`。
