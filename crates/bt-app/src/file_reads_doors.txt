#     no declaration, or two, is a refusal rather than a merged count.
#   trace.rs: create: .open    — the file, the bare name of the function the
#     door stands in, the door. P16 re-keyed every row whose item identity is
#     unique; the eight remaining file keys name duplicate free functions and
#     each group carries its reason beside the rows.
