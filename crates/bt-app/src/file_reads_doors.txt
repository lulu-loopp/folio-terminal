# A row is `<key>`, naming the owner one of two ways. Counts are deliberately
# not committed: the lane is the property, while call-site totals penalise
# harmless moves and duplicate the bare-effect census.
#   Runtime::turn: .open       — the item: the type the impl is for, the trait
#     if there is one, and the name. It says nothing about which file the item
#     is written in, so it does not change when the item moves. Every one of
#     these is put to the crate by file_reads_source_tests.rs, and a key naming
#     no declaration, or two, is a refusal rather than a merged count.
#   trace.rs: create: .open    — the file, the bare name of the function the
#     door stands in, the door. A row like this goes quiet the day its owner
#     moves to another file; these are the rows still on
#     docs/plans/MIGRATION-DEBT.tsv, and P16 of docs/plans/bt-app-split-prep.md
#     is the ticket that re-keys them.
